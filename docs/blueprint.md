# **App Name**: LocalFlag

## Core Features:

- Flag Toggle: Enable or disable predefined developer flags stored in local storage, such as 'isDeveloper'.
- Storage View: Display all current key-value pairs stored in local storage.
- Entry Addition: Add new, custom key-value pairs to local storage.
- Item Deletion: Remove individual items from local storage by specifying the key.
- Code Generation: Generate a JavaScript snippet for checking the status of 'isDeveloper' stored in the local storage. Use LLM as tool if needed.

## Style Guidelines:

- Background color: Dark gray (#222222) to create a dark theme.
- Primary color: Vibrant electric blue (#7DF9FF) for main UI elements and highlights.
- Accent color: Analogous light cyan (#90EE90) for secondary actions and subtle visual cues.
- Body font: 'Inter', a grotesque-style sans-serif for its modern and readable qualities. It's suitable for both headlines and body text.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use minimalist icons in electric blue to represent actions and storage items.
- Employ a clean, well-spaced layout to ensure information is easily scannable.
